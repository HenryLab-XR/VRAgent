## Metric definitions

- **SDC** = reference causal dependencies represented by an explicit operational TODG edge / all reference causal dependencies. Structural containment, component attachment, or prose inferred outside the graph does not count.
- **PIC** = required reference interaction actions expressible in the generated plan with the same interaction semantics / all required reference interaction actions. Direct method invocation does not substitute for physical placement or beam obstruction.
- **REC** = unique required runtime-event obligations observed / all unique required runtime-event obligations. Repeated observations of the same obligation count once.
- **SCR** = strictly completed reference scenarios / all reference scenarios. Completion requires required actions, causal events, ordering, and semantic postconditions; reaching the final state by a shortcut does not count.

## Interpretation

The plan is effective at forcing internal controller branches, but it is not yet a workflow-faithful interaction test. Room 2 bypasses `room2_trigger.OnTriggerEnter` and `SnapToTrigger.Snap`; Room 3 bypasses `LaserBeamSender.Update` and its raycast disconnection logic. Consequently, true postcondition records demonstrate branch reachability, not end-to-end scenario completion.

The TODG is primarily a structural scene graph. Its operationally relevant edge vocabulary is limited to tag relations; its other edge types describe containment and component attachment (`Has_Child`, `Has_Mono_Comp`, `Has_Collider`, `Has_Rigidbody`, `Source_Code_File`, and prefab information). It therefore identifies candidate participants but does not represent most callback, call, guard, state-transition, or postcondition dependencies required by the reference workflows.
